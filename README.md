# VTT GAME — builds

Pacotes Windows do **VTT GAME** (mesa virtual).

## Como instalar

1. Abra a página [Releases](https://github.com/MikhailNikolay/vtt-game-releases/releases/latest).
2. Baixe **VTTGame-windows.zip**.
3. Extraia tudo na mesma pasta.
4. Abra **Launcher.exe** (não o `VTTGame.exe` direto).

O launcher baixa só o que mudou nas próximas atualizações.

Este repositório contém apenas builds — não o código-fonte do jogo.
